# Z

### Zero-Knowledge Proofs (ZKPs) (fr : Preuves à divulgation nulle de connaissance)

Des techniques cryptographiques qui permettent à une partie de prouver qu’une affirmation est vraie sans révéler les informations secrètes qui la justifient.

→ [Cardano Developer Portal — Zero-Knowledge Proofs](https://developers.cardano.org/docs/developers/curriculum/smart-contracts/advanced/zero-knowledge/)

### zkRollup

Une solution de mise à l’échelle de couche 2 (_Layer 2_) qui regroupe plusieurs transactions hors chaîne et utilise une preuve de validité vérifiée sur la chaîne principale pour démontrer que les opérations regroupées respectent les règles définies.

Sur Cardano, **zkFold Rollup est une solution de mise à l’échelle en développement** qui utilise une preuve à divulgation nulle de connaissance pour vérifier plusieurs transactions regroupées. Il convient donc de distinguer cette initiative en développement d’une fonctionnalité native déjà intégrée au protocole de base de Cardano.

→ [Cardano.org — Layer 2 : solutions de mise à l’échelle](https://cardano.org/layer-2/)

→ [zkFold — Intégration de technologies ZK à Cardano](https://github.com/zkFold/zkfold-cardano)
