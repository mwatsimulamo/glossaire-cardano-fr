# U

## Unbonding (fr : Période de déblocage)

Désigne une période pendant laquelle les jetons délégués ou mis en staking ne peuvent pas être immédiatement retirés ou transférés. Alors que de nombreux réseaux à preuve d’enjeu (_Proof of Stake_, PoS) imposent une période de déblocage, Cardano permet de déléguer des ada sans période de blocage : les jetons restent liquides et transférables à tout moment.

### Untyped Plutus Core (UPLC) (fr : Plutus Core non typé)

Le langage de bas niveau, ou « langage machine », exécuté sur la chaîne par les nœuds Cardano pendant la validation des transactions.

### USDM

Un stablecoin indexé sur le dollar américain, émis sur Cardano par Moneta (anciennement Mehen Finance) et adossé à des réserves en dollars américains.

### Use Case (fr : Cas d’utilisation)

Une application ou un scénario spécifique dans lequel une technologie Cardano permet de résoudre un problème.

### Utility Token (fr : Jeton utilitaire)

Un type de jeton qui donne accès à des fonctions, des produits ou des services spécifiques au sein d’un réseau blockchain.

### UTXO (Unspent Transaction Output) (fr : Sortie de transaction non dépensée)

Un modèle de suivi des soldes dans lequel les jetons sont représentés par des sorties de transactions précédentes pouvant être dépensées dans de nouvelles transactions. Cardano étend ce modèle avec sa conception eUTXO (_Extended UTXO_).

### UTxO Cost per Byte (fr : Coût UTxO par octet)

Le paramètre du protocole qui fixe le coût de chaque octet de stockage occupé par un UTxO, utilisé pour déterminer le dépôt minimal requis.
