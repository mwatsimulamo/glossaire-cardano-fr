# D

## d parameter (fr : Paramètre d)

Le paramètre de protocole utilisé pendant l’ère Shelley qui contrôlait la proportion de blocs produits par les nœuds de genèse fédérés par rapport aux pools de staking communautaires.

## DApp (fr : Application décentralisée)

Une application dont la logique principale s’exécute sous forme de code sur la chaîne, plutôt que sur les serveurs d’une seule entreprise, de sorte que ses règles continuent de fonctionner même si un opérateur cesse ses activités.

## Datum (fr : Donnée associée à un UTxO)

Une donnée attachée à un UTxO qu’un contrat intelligent peut lire lorsqu’il détermine si cet UTxO peut être dépensé.

→ [Transaction costs and determinism — Cardano Docs](https://docs.cardano.org/about-cardano/learn/transaction-costs-determinism)

## Delegation (fr : Délégation)

Le processus consistant à attribuer son stake à un pool de staking sans transférer ses ada.

→ [Delegation — Cardano Docs](https://docs.cardano.org/about-cardano/learn/delegation)

## Determinism (fr : Déterminisme)

La propriété selon laquelle un calcul produit toujours les mêmes résultats lorsqu’il reçoit les mêmes entrées.

→ [Transaction costs and determinism — Cardano Docs](https://docs.cardano.org/about-cardano/learn/transaction-costs-determinism)

## DEX (fr : Plateforme d’échange décentralisée)

Une plateforme d’échange où les échanges sont exécutés par du code sur la chaîne plutôt que par un opérateur central. Les utilisateurs échangent directement depuis leur portefeuille et ne confient pas la garde de leurs fonds à un opérateur central.

## DID (fr : Identifiant décentralisé)

Un identifiant que l’on crée et contrôle soi-même, sans registre central ; l’enregistrement permettant de résoudre cet identifiant se trouve sur une blockchain ou un autre système décentralisé plutôt que dans la base de données d’une seule entreprise.

## Dijkstra

La prochaine ère du registre Cardano et le nom d’un hard fork, en hommage à Edsger Dijkstra. Sa première phase, ciblée pour la fin de 2026 selon le glossaire officiel, doit apporter Linear Leios et les transactions imbriquées (_nested transactions_). Une deuxième phase doit ajouter Peras.

## Djed

Un protocole de stablecoin surcollatéralisé par des cryptomonnaies sur Cardano, dont l’ancrage au dollar américain est maintenu de manière algorithmique à partir d’une réserve en ada, avec SHEN comme jeton de réserve, plutôt qu’au moyen de réserves en monnaie fiduciaire.

## DRep (fr : Représentant délégué)

Un représentant auquel les détenteurs d’ada délèguent leur pouvoir de vote sur la chaîne, afin qu’il vote en leur nom sur les actions de gouvernance.

→ [CIP-1694 — Spécification officielle](https://cips.cardano.org/cip/CIP-1694)

## DRep Activity Period (fr : Période d’activité des DReps)

Le paramètre du protocole qui définit le nombre d’époques pendant lesquelles un DRep peut rester sans voter ou mettre à jour son inscription avant d’être considéré comme inactif. Son pouvoir de vote délégué cesse alors d’être comptabilisé jusqu’à ce qu’il redevienne actif.

## DYOR (fr : Faites vos propres recherches)

Expression utilisée dans les communautés crypto pour rappeler aux personnes d’examiner elles-mêmes un projet, une équipe ou une affirmation avant d’investir ou d’agir, plutôt que de se fier uniquement aux arguments de quelqu’un d’autre.
